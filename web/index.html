UK bank details checker

Check a whole spreadsheet of sort codes and account numbers for typos, using the modulus-checking rules UK banks publish through Vocalink.

Your file never leaves this page. It's read and checked by Python running inside your browser. After the page has loaded, nothing is sent anywhere; you can confirm this in your browser's network tab.

1 Choose the rules

Made-up rules for fictional sort codes starting 99, so you can try the checker straight away. Don't use them for real bank details.

Download valacdos.txt and scsubtab.txt from Vocalink's modulus checking page, then choose them here. They update a few times a year, so use the latest.

2 Add your bank details

A CSV with a sort code column and an account number column. Any other columns are kept as they are. Download the template.

Using Excel? Format both columns as Text before typing, or Excel drops leading zeros (08-99-99 becomes 89999). Rows that look damaged are flagged for review, never guessed.
