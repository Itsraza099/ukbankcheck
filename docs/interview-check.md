# Interview-ready check

This project is done when I can answer all five questions **without notes**.
Write a short answer under each one as the project grows, then practise saying it out loud.

- [ ] **Walk me through the architecture.**

- [ ] **What happens if the same event arrives twice?**

- [ ] **How do you know the data is correct?**

- [ ] **What breaks first if usage grows 100×?**

- [ ] **What would you do differently?**
